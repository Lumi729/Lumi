☁️ Lumos 后台部署

你自己的 Cloudflare 后台会在页面关闭后生成回复，并向手机发送 Web Push。手机还需要允许浏览器通知及可用的推送网络。

1. 从仓库创建 Worker

  1. 打开 Cloudflare 控制台，进入 Workers & Pages，创建应用，选择导入 GitHub 仓库。
  2. 选择 Lumi729/Lumi，分支 main。
  3. Worker 名称填 lumos-background。根目录填 background；构建命令 npm ci && npm test；部署命令 npm run deploy。
  4. 部署后打开 https://你的Worker地址/health。初次显示 configured:false 是正常的，下一步添加密钥。
这是 Worker 项目，不选 Pages 静态站点。先使用 workers.dev 地址；自定义域名可以以后在 Worker 设置里绑定。

2. 在手机上生成后台密钥

点击后仅在此页面本地生成，不联网、不上传、不保存到浏览器。复制到 Cloudflare → 此 Worker → 设置 → 变量和机密，将四项都选为 Secret／机密，保存并部署。

不要把密钥发给任何聊天或提交到 GitHub。连接口令稍后还要填进 Lumos。已经配置好的后台不要随意重新生成、替换这些密钥，否则旧数据或手机订阅可能无法使用。

3. 在 Lumos 连接

  1. 重新打开 Lumos，进入要启用的单人角色，确认 AI 与自动回复已开启。
  2. 设置 → AI 回复 → 后台自动回复，填 Worker 根地址和 ACCESS_TOKEN 的值。
  3. 勾选上传同意，点“为当前角色启用后台”，允许通知。
  4. 点“测试手机推送”，检查通知栏。再把自动回复延迟设成 1 分钟，切后台等待，回来后点“同步后台消息”。

第一版接管一个单人角色。7 天不打开本机页面会暂停；每日次数仍受角色设置限制。通知送达还受手机系统、浏览器和推送服务网络影响。未看到通知时，回来同步仍可读取后台已生成的回复。
